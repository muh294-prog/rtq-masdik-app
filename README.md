# 📖 RTQ MASDIK - Aplikasi Manajemen Administrasi

Aplikasi web sederhana berbasis **Streamlit** dan **Python** untuk pengelolaan administrasi harian Rumah Tahfidz Qur'an (RTQ) MASDIK.

## 🚀 Fitur Utama
- **Dashboard / Catatan Harian**: Ringkasan statistik santri dan aktivitas harian guru.
- **Presensi Santri**: Pencatatan kehadiran harian santri (Hadir, Izin, Alfa).
- **Jurnal Mutaba'ah**: Catatan setoran hafalan Surah/Ayat dan perkembangan Iqra santri.
- **Data Santri**: Pengelolaan master data santri kelompok Hafalan dan Iqra.
- **Laporan & Rekap**: Export data rekapitulasi presensi dan mutaba'ah ke format CSV/Excel.

## 🛠️ Teknologi yang Digunakan
- Python
- Streamlit
- Pandas
